# DriveHub: Git Classroom Demo

Open `index.html` in a browser, or use VS Code Live Server. No installation,
JavaScript, account, or external images are needed to display the website.

The intentional `Contcat us` typo is a Git practice target, not an accidental error.
Search the HTML/CSS for `LAB-` comments to locate each practice target.

Read `PRACTICE_AR.md` for the instructor's ordered exercises and command mapping.
Start a fresh extracted copy for each independent exercise unless the guide says
to continue. The download intentionally contains no `.git` directory.

All vehicle names, prices, and contact information are fictional demonstration data.
